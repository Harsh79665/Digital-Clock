# Digital Clock

A simple desktop digital clock built with Python and Tkinter.

## Requirements

- Python 3.x
- Built-in `tkinter` and `datetime` libraries (no third-party packages needed)

## How to Run

```bash
python main.py
```

## Features

- Real-time hours, minutes, and seconds display
- 12-hour (with AM/PM) and 24-hour time format toggle
- Current date and day of the week
- Toggle visibility for seconds and date
- Dark and light mode
- Fullscreen mode (toggle with the button or press `F11`, press `Escape` to exit)
- Always on Top option to keep the clock pinned over other windows
- Responsive text that scales when resizing the window
- Clean and straightforward layout with no unnecessary dependencies
